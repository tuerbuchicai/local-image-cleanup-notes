# Visible and invisible mark boundaries

## Visible image marks

A visible mark is something a person can point to in the image pixels, such as a small label, logo, text overlay, or piece of clutter. The local workflow lets the user select that visible area manually and review the repair.

## Invisible provenance signals

Invisible provenance signals are not the same as visible pixels. This reference pack does not provide a way to detect, verify, remove, or alter metadata-based provenance information or invisible watermarking signals.

## Rights boundary

Removing a visible mark does not establish a right to reuse an image. The person using the workflow remains responsible for having permission to edit and use the source image.
